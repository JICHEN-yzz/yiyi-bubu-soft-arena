# 一二布布：软糖拳台

2.5D 跨设备格斗游戏。使用重新校准比例的圆润角色 GLB，包含单人对 AI、本机双人、房间码联机、三局两胜、防御、投技、必杀和软萌晕倒表现。

## 启动

双击 `启动游戏.bat`，或在项目目录运行：

```powershell
npm start
```

然后打开 `http://localhost:4173`。控制台会同时输出可以给同一 Wi-Fi 下其他设备使用的地址。

Three.js 运行文件已经放在 `vendor/` 中，不需要联网下载依赖。

## 跨设备联机

1. 房主打开“跨设备联机”，输入昵称并创建房间。
2. 点击“复制”取得邀请链接，发给另一位玩家。
3. 对方在自己设备打开链接、输入昵称并加入；房主点击“开始跨设备对战”。

同一 Wi-Fi 下可以直接使用控制台输出的局域网地址。若两人不在同一网络，需要把整个目录部署到支持 WebSocket 的 Node 主机，例如 Render、Railway 或一台带公网域名的服务器。设置环境变量 `PUBLIC_URL=https://你的域名` 后，生成的邀请链接会自动使用公网地址。

`临时公网分享.bat` 只适合几分钟的应急试玩。它的地址依赖分享进程，进程关闭或隧道掉线后就会失效，不建议作为给另一半的常用入口。

## 长期公共网址

项目已经带好 `render.yaml`，可以部署成地址固定的 Node Web 服务：

1. 把 `yiyi_bubu_fight` 整个文件夹上传到一个 GitHub 仓库。
2. 在 Render 新建 Blueprint，并选择这个仓库。配置中的启动命令和健康检查已经写好，不需要另外安装依赖。
3. 部署完成后会得到一个固定的 `https://名称.onrender.com` 地址。以后双方都从这个地址进入，再创建或加入房间。

服务会自动识别 Render、Railway、Vercel 和 Fly.io 提供的公开域名。Render 免费实例长时间没人访问时会休眠，重新打开可能需要等待约半分钟，但网址本身不会像临时隧道那样几分钟就变。

若使用自己的服务器，启动时设置 `PUBLIC_URL=https://你的域名`，生成的邀请链接就会固定使用该域名。

## 操作

玩家一：`A/D` 移动，`W` 跳跃，`S` 防御，`J` 轻击，`K` 重击，`L` 特殊技，`O` 第二特殊技，`U` 投技，`I` 必杀。

玩家二：方向键移动、跳跃、防御，`1` 轻击，`2` 重击，`3` 特殊技，`4` 第二特殊技，`5` 投技，`6` 必杀。

跨设备联机时，双方都使用玩家一的操作键位，各自控制自己设备上的角色。

手机技能键使用两字动作名，例如“突进”“回旋”“抱摔”，完整招式名会显示在技能栏和命中提示中。

## 角色选择与图鉴

- 开场页面可在“一二”和“布布”之间切换出战角色，选择会自动记住。
- 单人对战中，AI 自动使用另一位角色；本机双人也会自动分配另一角色。
- 跨设备联机时，双方各自选择角色；如果两人选了同一角色，后加入的一方会自动换用另一位，避免两边模型重叠。
- 点击“角色图鉴”可查看角色定位、速度/力量/防御/连招数值、六项技能的伤害、冷却、用法说明与实战建议。

## 手机操作

- 手机浏览器会自动切换为触控界面，桌面浏览器仍显示键鼠提示。
- 左侧方向键控制移动，`跳`用于跳跃，`防`用于防御。
- 右侧六个按键依次对应特殊技、第二特殊技、投技、轻击、重击和必杀。
- 支持多个触点同时操作，例如左手移动、右手攻击。
- 横屏时游戏会尝试全屏并锁定横屏；iPhone 若不允许网页锁定方向，可按页面提示手动旋转。
- 页面包含 Web App Manifest，可添加到手机主屏幕后以横屏应用方式启动。

`Esc` 暂停。
